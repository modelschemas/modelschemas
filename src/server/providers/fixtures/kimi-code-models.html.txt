data-v-872e0668><p class="custom-block-title" data-v-872e0668>Need a higher membership plan?</p><p data-v-872e0668>Different membership plans unlock different models, context windows, and speeds. <a href="https://www.kimi.com/code/#pricing" target="_blank" rel="noreferrer" data-v-872e0668><strong data-v-872e0668>Upgrade your plan →</strong></a></p></div><details class="details custom-block" data-v-872e0668><summary data-v-872e0668>Why did usage go up after the new model launched?</summary><p data-v-872e0668>After switching models, the context cache built earlier no longer hits on the new model, so that context has to be re-prefilled. Usage therefore looks higher right after switching. Recommended action:</p><ul data-v-872e0668><li data-v-872e0668><strong data-v-872e0668>Start a new session when using the new model</strong>: this gives better results and lower consumption.</li></ul></details><details class="details custom-block" data-v-872e0668><summary data-v-872e0668>Why do I still get a 401 with the correct model ID?</summary><p data-v-872e0668>When the requested capability exceeds your plan&#39;s entitlements, the server returns <code data-v-872e0668>401</code>. Three common cases:</p><ul data-v-872e0668><li data-v-872e0668><strong data-v-872e0668>No K3 access</strong>: your plan is below Moderato / Plus and can&#39;t call <code data-v-872e0668>k3</code>, <code data-v-872e0668>k3-256k</code> (the new Go tier has no coding quota) — upgrade to Moderato / Plus or above.</li><li data-v-872e0668><strong data-v-872e0668>No 1M access</strong>: on a Moderato / Plus plan, <code data-v-872e0668>k3</code> supports up to 256K context; up to 1M context is available on Allegretto / Pro or above. <code data-v-872e0668>k3-256k</code> has a fixed 256K context limit.</li><li data-v-872e0668><strong data-v-872e0668>No HighSpeed access</strong>: some plans don&#39;t include HighSpeed — upgrade to Allegretto / Pro or above to call <code data-v-872e0668>kimi-for-coding-highspeed</code>.</li></ul><p data-v-872e0668>For the full error text and how to handle it, see the <a href="/code/docs/en/kimi-code/error-reference.html" data-v-872e0668>Error Reference</a>.</p></details><details class="details custom-block" data-v-872e0668><summary data-v-872e0668>Why isn&#39;t HighSpeed noticeably faster?</summary><p data-v-872e0668>Two common reasons:</p><ul data-v-872e0668><li data-v-872e0668><strong data-v-872e0668>Mistyped model ID</strong>: the HighSpeed ID must be <code data-v-872e0668>kimi-for-coding-highspeed</code>; a wrong value silently falls back to the standard <code data-v-872e0668>kimi-for-coding</code> — no error, no speedup.</li><li data-v-872e0668><strong data-v-872e0668>Tools and scripts dominate</strong>: HighSpeed only speeds up <strong data-v-872e0668>model output</strong>. Tool calls (reading/writing files, running commands, etc.) and script execution are unaffected, so when they take up most of a turn the overall speedup feels small.</li></ul></details><details class="details custom-block" data-v-872e0668><summary data-v-872e0668>How to reduce the overhead of switching reasoning effort?</summary><p data-v-872e0668>Switching reasoning effort invalidates the context cache you&#39;ve built up, so context that would have hit the cache must be re-prefilled. To avoid triggering re-prefill too often:</p><ul data-v-872e0668><li data-v-872e0668>Pick an effort that fits the task and keep it consistent within a session;</li><li data-v-872e0668>When you genuinely need a different effort, start a new session rather than switching back and forth in a long session.</li></ul></details><details class="details custom-block" data-v-872e0668><summary data-v-872e0668>Switching between K3 (1M) and K3-256k</summary><p data-v-872e0668><strong data-v-872e0668>Switching from K3 (1M) to K3-256k</strong>: if the current session&#39;s context already exceeds 256k, some coding tools (such as Kimi Code CLI and Claude Code) will perform a compact on the tool side. Recommendations:</p><ol data-v-872e0668><li data-v-872e0668>Manually run compact once before switching to compress the context to within 256k. This preserves the key points of the task, keeps the session intact, and lets you benefit from more durable quota after switching.</li><li data-v-872e0668>If the conversation history includes video files, switching directly will fail because K3-256k does not support video input. Please compact first, then switch.</li></ol><p data-v-872e0668><strong data-v-872e0668>Switching from K3-256k to K3 (1M)</strong>: if <code data-v-872e0668>k3-256k</code> is close to the 256k limit and you don&#39;t want compact to lose information, you can switch directly to 1M. The current version switching from 256k to 1M does not affect the cache.</p></details><h2 id="switch-model" tabindex="-1" data-v-872e0668>How to Switch Models <a class="header-anchor" href="#switch-model" aria-label="Permalink to “How to Switch Models”" data-v-872e0668>​</a></h2><div class="warning custom-block" data-v-872e0668><p class="custom-block-title" data-v-872e0668>Usage notes</p><ul data-v-872e0668><li data-v-872e0668><strong data-v-872e0668>Start a new session when switching model IDs</strong>: switching models invalidates the context cache you&#39;ve built up. We recommend starting a new session to get the best experience and avoid extra token consumption.</li><li data-v-872e0668><strong data-v-872e0668>Fill in the Model ID, not the model version name</strong>: when calling a model, use one of the Model IDs from the table above (<code data-v-872e0668>k3</code>, <code data-v-872e0668>k3-256k</code>, <code data-v-872e0668>kimi-for-coding</code>, <code data-v-872e0668>kimi-for-coding-highspeed</code>). Entering a model version name like <code data-v-872e0668>K3</code> or <code data-v-872e0668>K2.8 Preview</code> will cause the call to fail.</li><li data-v-872e0668><strong data-v-872e0668>Thinking off routes to K2.8 Preview (no thinking)</strong>: with thinking disabled, requests to the K3 series and K2.8 Preview are served by K2.8 Preview with thinking off.</li></ul></div><p data-v-872e0668>Ways to switch to the target model:</p><h3 id="official-clients" tabindex="-1" data-v-872e0668>Official clients <a class="header-anchor" href="#official-clients" aria-label="Permalink to “Official clients”" data-v-872e0668>​</a></h3><ul data-v-872e0668><li data-v-872e0668><strong data-v-872e0668>Kimi Code Desktop</strong>: switch models in the model picker inside the Composer; if the target model isn&#39;t listed yet, restart the app or sign in again.</li><li data-v-872e0668><strong data-v-872e0668>Official Kimi Code CLI</strong>: type <code data-v-872e0668>/model</code> to switch models—no config changes needed; if the latest model isn&#39;t listed yet, <code data-v-872e0668>/logout</code> and sign in again with <code data-v-872e0668>/login</code>.</li><li data-v-872e0668><strong data-v-872e0668>Kimi Code for VS Code</strong>: pick the target model from the dropdown menu in the input bar; if it isn&#39;t listed yet, restart VS Code or reinstall the extension.</li></ul><h3 id="third-party-tools" tabindex="-1" data-v-872e0668>Third-party tools <a class="header-anchor" href="#third-party-tools" aria-label="Permalink to “Third-party tools”" data-v-872e0668>​</a></h3><p data-v-872e0668>Set the tool&#39;s Model ID to the target model.
